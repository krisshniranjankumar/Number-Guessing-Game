# Number Guessing Game 

A simple number guessing game built with Python and Tkinter.

##  Description

This is an interactive number guessing game where the computer generates a random number, and the player tries to guess it. The game provides hints (too high/too low) to help the player find the correct number. Built using Python's Tkinter library for a graphical user interface.

##  Features

- Graphical User Interface (GUI) using Tkinter
- Random number generation
- Hint system (Too High / Too Low)
- Attempt counter
- User input validation (only allows integers)

##  How to Run

### Prerequisites
- Python 3.x installed on your system
